## 6.1 Python Pydantic→Java POJO 映射规则

|Python Pydantic|Java 等价|说明|
|---|---|---|
|BaseModel|record 或 @Validated POJO|不可变用 record，可变用POJO|
|Field(default=...)|Jackson @JsonProperty(defaultValue=...)|默认值|
|validator|Jakarta @Valid ＋自定义ConstraintValidator|校验逻辑|
|model_dump()|ObjectMapper.writeValueAsString()|序列化|
|model_validate()|ObjectMapper.readValue()|反序列化|
|Optional[T]|@Nullable T或 Optional<T>|可空字段|
|Union[A, B]|sealed interface permits|联合类型|
|Literal["a","b"]|enum|枚举字面量|
|constr(min_length=1)|@NotBlank @Size(min=1)|字符串约束|
|confloat(ge=0, le=1)|@DecimalMin("0") @DecimalMax("1")|数值约束|

### 6.1.1 Jackson 全局配置（对齐 Pydantic 序列化行为）

Python Pydantic v2 的 `model_dump_json()` 默认行为与 Jackson 存在差异。所有模块**必须**使用 `openharness-common` 中统一定义的 `OpenHarnessObjectMapper`，禁止自行构造 `ObjectMapper`。

```java
public final class OpenHarnessObjectMapper {
    private static final ObjectMapper INSTANCE = new ObjectMapper()
            // 对齐 Pydantic 的 exclude_none=true：不序列化 null 字段
            .setSerializationInclusion(JsonInclude.Include.NON_NULL)
            // 对齐 Pydantic 的枚举序列化为字符串
            .configure(SerializationFeature.WRITE_ENUMS_USING_TO_STRING, true)
            .configure(DeserializationFeature.READ_ENUMS_USING_TO_STRING, true)
            // 对齐 Pydantic 的 Instant 序列化为 ISO-8601 字符串（带 Z）
            .registerModule(new JavaTimeModule())
            .disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS)
            // 允许未知字段（兼容前端协议演进）
            .disable(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES)
            // Sealed Interface 多态序列化，对齐 Python Union 的 type 判别
            .setPolymorphicTypeValidator(new NoCheckSubTypeValidator())
            .activateDefaultTyping(
                BasicPolymorphicTypeValidator.builder().build(),
                ObjectMapper.DefaultTyping.NON_FINAL,
                JsonTypeInfo.As.PROPERTY
            );

    public static ObjectMapper get() { return INSTANCE; }
}
```

**Phase 0 验证门禁**：前端协议兼容性测试必须使用 `OpenHarnessObjectMapper.get()` 进行 JSON 序列化/反序列化，确保输出与 Python 版 `model_dump_json()` 逐字段对齐。

# 七、异步模型映射

## 7.1 Python asyncio→Java Virtual Threads

|Python 模式|Java 等价|说明|
|---|---|---|
|async def|普通方法＋Virtual Thread|Virtual Thread 自动挂起|
|await|直接调用（阻塞当前虚拟线程）|不阻塞平台线程|
|asyncio.gather(*tasks)|StructuredTaskScope / CompletableFuture.allOf() + supplyAsync|并行执行：工具调用优先用 StructuredTaskScope（自动取消子任务），通用异步编排用 CompletableFuture|
|asyncio.create_task()|Thread.ofVirtual().start()|启动后台任务|
|asyncio.Queue|BlockingQueue（在虚拟线程中安全）|任务队列|
|asyncio.Event|CountDownLatch / Phaser|事件通知|
|asyncio.Semaphore|Semaphore|并发限制|
|async for|Stream<T> / Iterator<T>|流式迭代|
|async with|try-with-resources|资源管理|

## 7.2 并行工具执行示例

```java
// Python 原版：asyncio.gather(*coroutines)
// Java 等价：StructuredTaskScope（自动取消子任务 + 统一异常传播）

public List<ToolResult> executeParallelTools(List<ToolCall> toolCalls, ToolContext ctx) {
    try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
        List<StructuredTaskScope.Subtask<ToolResult>> subtasks = toolCalls.stream()
                .map(tc -> scope.fork(() -> {
                    BaseTool<?> tool = toolRegistry.get(tc.name());
                    return tool.execute(tc.arguments(), ctx);
                }))
                .toList();

        scope.join()           // 等待所有子任务完成
             .throwIfFailed(); // 任一失败则取消其余任务并抛出异常

        return subtasks.stream()
                .map(StructuredTaskScope.Subtask::get)
                .toList();
    } catch (Exception e) {
        return List.of(ToolResult.error("Tool execution failed: " + e.getCause().getMessage()));
    }
}
```
