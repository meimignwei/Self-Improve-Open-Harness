### 4.9.1 React 后端协议（关键兼容层）

Java 后端通过 JSON-Lines 协议与 TypeScript React/Ink 前端通信，每行一个 JSON 对象。后端发送 `BackendEvent`（17 种子类型，4.9.2 节详述），前端发送 `FrontendRequest`（5 种子类型，4.28.2 节详述）。协议完全对齐 `frontend/terminal/src/types.ts` 中的 TypeScript 类型定义，确保后端语言替换后前端无需改动。
