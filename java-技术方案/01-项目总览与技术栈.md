# 一、项目总览与技术栈

> **源码锚点**：本文档为全局概述，无单一对应源码文件。涉及具体技术选型理由可查看 `pyproject.toml` 和 `src/openharness/` 各模块的 `__init__.py`。

---

## 1.1 OpenHarness 是什么

OpenHarness 是一个开源的AI编码助手CLI框架（"Agent Harness")，核心理念是＂模型是智能体，代码是线束＂。它为LLM提供工具调用、权限治理、多智能体协调、上下文管理、持久记忆等完整的生产级基础设施。

## 1.2 核心数据

|指标|数值|
|---|---|
|Python 源文件数|249个|
|顶层包数|36个（含 ohmo）|
|内置工具数|44个|
|内置技能数|8个（bundled）+ 支持用户/项目/插件技能加载|
|支持LLM提供商|20＋个|
|支持消息渠道|10个（已完整实现）|
|单元／集成测试|114＋个|
|E2E 测试场景|6个 suites|

## 1.3 复刻目标

1. 核心功能完整复刻：OpenHarness Core（引擎、工具、权限、记忆等）+ ohmo 个人代理层（Gateway、Workspace、Session Pool）
2. API协议兼容：前端TUI可无缝切换Java 后端
3. 可观测性增强：新增Metrics、Distributed Tracing、Structured Logging 三大支柱（原Python版无此能力）
4. 云原生就绪：支持容器化部署、Kubernetes 编排、Helm Chart

## 二、技术栈选型

### 2.1 核心框架

|层次|Python（原版）|Java（复刻版）|选型理由|
|---|---|---|---|
|语言版本|Python 3.10+|Java-21+(LTS)|Virtual Threads 替代 asyncio，Pattern Matching 替代 Python match|
|构建工具|hatchling/pip|Maven 3.9+（多模块 POM）|多模块构建、依赖管理、成熟稳定的Java 标准构建工具|
|CLI框架|Typer|Picocli 4.x|注解驱动、子命令、自动补全、GraalVM native-image 兼容|
|异步运行时|asyncio|Java 21 Virtual Threads + CompletableFuture|Virtual Threads 执行阻塞 I/O，CompletableFuture 编排异步任务|
|数据验证|Pydantic v2|Jakarta Validation + Jackson|JSON Schema 生成、注解校验|
|HTTP 客户端|httpx|Java HttpClient(JDK 21)+ OkHttp 4.x|SSE流式、WebSocket、连接池|
|WebSocket|websockets|Java-WebSocket/Tyrus|渠道接入|
|JSON 处理|stdlib json|Jackson 2.x|流式解析、Pydantic 等价的POJO映射|
|YAML 处理|PyYAML|SnakeYAML 2.x|技能／记忆frontmatter 解析|
|模板引擎|f-string/jinja2|String Template 4/Mustache|系统提示词组装|
|进程管理|subprocess/asyncio.subprocess|ProcessBuilder + Process API|工具执行、沙箱|
|文件监听|watchfiles|Java WatchService/Apache Commons IO|Hook 热重载|
|调度|croniter|cron-utils + ScheduledExecutorService|Cron 表达式解析与轻量调度（Quartz 过于重量级）|
|终端UI|Rich/Textual/prompt-toolkit|无需后端实现|前端为独立 TypeScript/React Ink 应用，后端仅输出 JSON-Lines|
|测试框架|pytest/pytest-asyncio|JUnit 5 + Mockito + Testcontainers|异步测试、容器化集成测试|

### 2.2 可观测性技术栈

|维度|技术选型|说明|
|---|---|---|
|Metrics|Micrometer 1.x+Prometheus Registry|指标采集、直方图、计数器、Gauge|
|Tracing|OpenTelemetry Java SDK+ OTLP Exporter|分布式链路追踪，支持Jaeger/Zipkin/Tempo|
|Logging|SLF4J 2.x + Logback+Logstash Encoder|结构化JSON日志，TracelD/SpanID 自动注入|
|Health Check|自定义／health +/ready 端点|Kubernetes 探针兼容|
|Metrics 暴露|Prometheus HTTP Exporter（内嵌）|／metrics 端点，Prometheus 抓取|
|Dashboard|Grafana 预置面板|Agent Loop、Tool执行、LLM API 调用可视化|

### 2.3 前端保持不变

前端TUI是独立的TypeScript+React/Ink 终端应用，通过JSON-Lines 协议与后端通信。Java 后端只需实现相同的JSON-Lines协议即可无缝对接，前端无需改动。

**源码锚点**：前端类型定义在 `frontend/terminal/src/types.ts`，后端协议在 `src/openharness/ui/protocol.py`。
